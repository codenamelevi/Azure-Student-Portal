# Azure Student Portal

## Overview

This project is a beginner cloud computing project built using Microsoft Azure.

The project demonstrates how Azure services work together to create a cloud-hosted student portal with file storage and secure access.

---

# Features

* Windows Virtual Machine
* IIS Web Hosting
* Azure Networking
* Network Security Groups (NSGs)
* Azure Blob Storage
* Secure File Access using SAS Tokens
* HTML & CSS Frontend

---

# Azure Services Used

| Service         | Purpose                      |
| --------------- | ---------------------------- |
| Virtual Machine | Hosted the website           |
| IIS             | Web server                   |
| VNet            | Private networking           |
| NSG             | Firewall/security            |
| Storage Account | Cloud storage                |
| Blob Containers | Organized file storage       |
| SAS Tokens      | Temporary secure file access |
